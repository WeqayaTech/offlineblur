1. Architecture

One vision transformer with over a billion parameters reads the whole frame once. Two branches consume its output: an end-to-end transformer tracker that carries a learned query per person across frames, and a cross-attention head that reads each person's demographics straight from the shared token map without cropping pixels. A Bayesian aggregator turns the per-frame guesses into one locked profile per track.

Phase 1 · shared feature extraction — stp/backbone.py

DINOv2-giant sees the full frame. The frame is resampled so one 14-px patch covers 8 source pixels, then processed as overlapping 64×64-token tiles blended with a Hann window; tiles with no tracked person are skipped. A 60-px background person becomes an 8×15-token region. InternImage-H was evaluated and rejected: its public head only exposes stride-32 pooled features.

Phase 2 · tracking with track queries — stp/tracker.py

MOTRv2 and MeMOTR run through their official submit scripts, unmodified, on a MOT-layout frame sequence. Each person is a query the decoder carries across frames; a hidden person's query survives up to 300 frames and re-attaches without a new id. MOTRv2 takes YOLO11x person proposals as anchor queries. Both trackers resample to 800×1536 internally.

Phase 3 · demographics by cross-attention — stp/roi_attention.py

For each tracked box the head gathers the backbone tokens inside the box (+15 % margin), gives them box-relative sine positions, and lets 8 learned queries run 3 layers of self-attention, cross-attention and feed-forward over them. Outputs: 2-way gender, a 101-bin age distribution (mean and std), a quality logit trained to predict "this frame's answer is right", and the cross-attention entropy (flat attention = nothing to focus on). It is the only trained component: 161 k images (UTKFace, FairFace, CelebA) rendered at random short sides of 56–448 px with blur, JPEG and margin augmentation, 4 epochs, 108 minutes.

Phase 4 · Bayesian temporal pooling — stp/aggregator.py

Per frame, weight w = quality × gsize × gocclusion × gsharpness × (1 − entropy). Gender accumulates a Beta posterior, age a precision-weighted Gaussian product of experts. A clear look (w ≥ 0.8) counts three times. Once evidence ≥ 8 and the posterior ≥ 0.9 on one side, the profile locks and later weak frames are damped. A track query riding ≥ 90 % inside a locked person's box with 5× less evidence is treated as a duplicate: it inherits a male host's class, and becomes "unknown" under a female host, so the rule can suppress a blur but never create one.

Phase 5 · blur renderer — stp/blur.py

Targets are identities whose pooled gender is female with P ≥ 0.6 or locked, never children or unknowns. Each frame is segmented once with YOLO11x-seg; the instance with the best IoU to the target box becomes the mask, clipped to the box so it cannot bleed onto a neighbour, then dilated, feathered and pixelated with a block size relative to that person's height. Outputs: blurred video with original audio, a soft matte, and per-frame RLE masks for every identity.

4. What was done, in order

  • Fetched the exact submit interfaces of the MeMOTR and MOTRv2 repositories and wrote adapters that drive them unmodified (MOT-layout frames in, MOT text out).
  • Wrote the tiled dense-feature backbone, the cross-attention ROI head, the per-frame demographics runner, the Bayesian aggregator, a debug renderer and a contact-sheet tool.
  • Set up the A100 pod on its container disk (no network volume), compiled the Deformable-Attention CUDA op for both trackers, and resolved four install traps: xet downloads failing with "disk quota exceeded", transformers ≥ 4.57 silently disabling torch 2.4, the gdown flag change, and a module name shadowing the Hugging Face datasets package.
  • Exported 161 k labelled faces from Hugging Face (UTKFace, FairFace, CelebA) and trained the head for 4 epochs with a threaded prefetcher (2.3 steps/s, GPU 95 %).
  • Ran four tracker variants on the clip while training, and picked MOTRv2 from the frames.
  • Ran the full pipeline with the epoch-1, epoch-3 and final heads; measured that the pooled ROI embeddings are attribute features (cosine 0.96 between different people) and therefore unusable for identity relinking, so relinking stays off.
  • Wrote the blur renderer, found a false blur on a duplicate query of the reporter and a coverage rule that absorbed people walking behind the interviewee, and fixed both: the duplicate rule can only suppress a blur, and the default blur threshold is P ≥ 0.6 with a 0.5–0.6 review band.
  • Committed everything to the repository with a README and design report.

6. Limits and next steps

  • Body-view demographics. The head was trained on faces; back views land near 0.3–0.55. Fix: add pedestrian-attribute data (PA-100K, PETA, Market-1501 attributes) or distil labels from the v1 Qwen vote on the six-clip corpus, then retrain (about two hours).
  • Age compression. Ages cluster in the mid-30s on this clip (an older man reads 43 ± 3); exact-age data for older faces is needed.
  • Track id switches still happen in dense crossings (one woman's track merged with a man's). Identity relinking needs a real re-identification embedding, not the attribute head's pooled vector.
  • Backbone swap (giant backbone inside the tracker) only if tracker misses, not the head, turn out to be the limit on 4K footage: 8× H100, days.
  • Run: bash v2/pod_setup_v2.sh · EPOCHS=4 bash v2/train_head.sh · bash v2/run_v2.sh clip.mp4 (tracks → attrs → identities → debug video → blurred video).
